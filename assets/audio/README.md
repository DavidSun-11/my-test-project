# Audio

本目录用于放本地网页音频文件。

当前页面播放器读取：

```text
assets/audio/music.mp3
```

请注意：浏览器和 GitHub Pages 不能直接播放网易云 `.ncm` 加密文件，只能播放标准 MP3 等浏览器支持的音频格式。

你本地 `D:\CloudMusic\VipSongsDownload` 中目前找到的《感谢你曾来过》文件是：

```text
music.ncm
```

它不是 MP3。若要让网页播放，请先取得/转换为真正的 MP3，并在确认拥有公开发布/托管授权后上传到：

```text
assets/audio/music.mp3
```

GitHub Pages 不能读取你电脑上的 `D:\CloudMusic\VipSongsDownload` 路径，只能读取仓库内的公开文件。
